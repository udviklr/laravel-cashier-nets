# Security Policy

## Supported Versions

Security updates are provided for the current stable major release.

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report suspected vulnerabilities privately through GitHub's private vulnerability reporting feature, if it is enabled for this repository. If private vulnerability reporting is not available, email the maintainer at magnus@udviklr.dk.

Include enough detail to reproduce and assess the issue:

- The affected package version.
- A clear description of the vulnerability.
- Steps to reproduce, proof of concept, or relevant code snippets.
- Any known impact on payment, webhook, subscription, or credential handling.

You should receive an initial response within 5 business days. Confirmed vulnerabilities will be handled with coordinated disclosure and released as patched versions as appropriate.
